Application Security

Building TPT: From alert chaos to clear priorities

Onsdag 10:00–10:40 1 · Frimurerlosjen, rom 1

EnglishDetailed 40 min

Foredragsholder

Emil Albrektsson

Application Security @ NAV

Application security developer & security champion advocate

Om sesjonen

Applications generate hundreds of vulnerability alerts, but which ones actually matter? Nav's AppSec team built TPT (Titt på Ting), an open-source tool that helps remediate this problem using free data sources. In this talk, I'll share how we transformed overwhelming vulnerability backlogs into actionable, prioritized workflows. Learn about our risk-scoring approach, how we aggregate data from multiple free sources, and the UX principles that help developers prioritize.
