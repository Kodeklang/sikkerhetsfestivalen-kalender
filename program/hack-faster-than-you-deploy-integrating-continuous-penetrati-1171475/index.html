Om sesjonen

In a world of hourly deployments and ephemeral cloud infrastructure, the "annual penetration test" has become a historical document the moment it’s published. Most organisations are left with a dangerous "security gap"—the period between tests where new code, misconfigurations, and 0-days go undetected.

This session explores the transition from traditional, point-in-time security audits to Continuous Penetration Testing (CPT). We will dive into how organizations can weave offensive security into the very fabric of their product development cycle—from the first line of code to the production environment.
