Om sesjonen

Unmanaged Linux desktops are a growing blind spot in enterprise security. In this session, we'll show how to close that gap by building a scalable, secure Linux desktop platform using Microsoft Intune and Chef. Topics include security baselines, CIS benchmarks, configuration management and endpoint visibility – giving security teams the same control over Linux that they already have over Windows.
